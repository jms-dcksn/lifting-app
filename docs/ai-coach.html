How the in-app Coach talks to the ledger

This page teaches the shipped Slice 0 agent. The deterministic Track Coach still owns the numbers. The agent is a talking layer on top of loaders you already have.

The path of one question

You tap the chat button (or open /coach). The browser sends your words to a server route. That route proves you are signed in, writes your message to Postgres, asks LangChain to think, and streams the reply back. LangChain may call a tool. Each tool is a thin wrapper around an existing loader. LangSmith records the trace so you can see which tools ran.

“How was this week?”

The model is not allowed to invent adherence. It must call weeklyCoach, which calls loadCoachUi — the same function Track Coach uses. The answer then names that source.

Full transcript vs last N

Every message is saved. Reload /coach and you see the whole thread, including tool-call parts. The model does not get the whole thread. Each turn takes the system prompt plus the last CONTEXT_MESSAGE_LIMIT messages (20). If that window is still large, old tool JSON is stubbed out first. User and assistant sentences stay. There is no summarizer and no embeddings.

Postgres (UI)

All turns, all tool parts. One thread per user.

Model window

System prompt + last 20. Prefer dropping old tool results before dropping words.

Who owns what

If the agent computed a squat target itself, Home and the session screen would drift. So the engine keeps the math. The agent only narrates.

Engine

Numbers, prescriptions, stalls, Last / 21-day / chart summaries, sessionTarget().

Agent

Language, which tool to call, citing the source, refusing diagnosis and writes.

src/lib/agent/tools/weekly-coach.ts — wrap, do not fork

export async function weeklyCoach(supabase: Client, userId: string) {
  const loaded = await loadCoachUi(userId, supabase);
  return {
    source: "weeklyCoach" as const,
    checkInText: loaded.coachCheckIn,
    report: loaded.coachReport,
    recommendations: loaded.coachRecommendations,
    decisions: loaded.decisions,
  };
}

The LangChain tool() adapter sits beside this. The public interface is the function, not the adapter.

src/app/api/agent/chat/route.ts — cookie auth, not the weekly secret

const handlers = createAgentChatHandlers({
  async auth() {
    const supabase = await createClient();
    const { data } = await supabase.auth.getClaims();
    const userId = data?.claims?.sub as string | undefined;
    return { supabase, userId: userId ?? null };
  },
});

Unauthenticated requests get 401 before any tool runs. Tools never receive SUPABASE_SECRET_KEY or COACH_API_TOKEN.

What Slice 0 will not do

  • Write programs, start sessions, or accept Coach proposals.
  • Read period observations.
  • Replace Track Coach at /analytics/coach.
  • Summarize, compact, or embed the conversation.
